## 1. Mục tiêu

Toàn bộ chuỗi hiển thị của SPA nằm trong `frontend/src/i18n/vi.json`, được nạp qua một thư viện i18n và được lint chặn chuỗi viết cứng. Phía AI, prompt luôn yêu cầu trả lời **cùng ngôn ngữ với câu hỏi**, có test tự động. Thêm ngôn ngữ sau này (khi OQ-009 chốt) chỉ cần thêm một file JSON.

## 2. Bối cảnh

- BR-015 / **AC-015**: "Câu hỏi bằng mỗi ngôn ngữ được phê duyệt nhận câu trả lời bằng cùng ngôn ngữ đó, đạt tiêu chí AC-008." Danh sách ngôn ngữ **`[TBD: OQ-009]`** (tiếng Việt và/hoặc tiếng Anh).
- [Implement_plan §4.2](../Implement_plan.md#42-frontend): chuỗi hiển thị đặt trong `i18n/vi.json`, không viết cứng trong component; [§9.1](../Implement_plan.md#91-quyết-định-cần-có-và-ảnh-hưởng-tới-lập-trình): chưa có OQ-009 → chỉ tiếng Việt.
- Prompt sinh câu trả lời: "trả lời cùng ngôn ngữ câu hỏi" ([SAD §3.2.1](../../design/SAD.md) bước 10; Blueprint DD-06 bước 6) — prompt v1 ở T-206. Embedding đa ngữ (AD-08) thuộc T-208/SP-04.
- [User_Stories US-C8](../../design/User_Stories.md#us-c8): thiết kế chỉ có giao diện tiếng Việt; **không** làm màn chuyển ngôn ngữ cho tới khi OQ-009 được giải quyết.
- Sự kiện `question_asked` có thuộc tính `language` (PRD §5.2).

## 3. Phạm vi

**Trong phạm vi**
- Cài và cấu hình thư viện i18n; `vi.json` là ngôn ngữ mặc định và duy nhất.
- Chuyển mọi chuỗi đang viết cứng (trang 01–09, component dùng chung, thông báo lỗi theo mã) sang khóa.
- Quy tắc ESLint chặn chuỗi viết cứng trong JSX + script kiểm khóa thiếu/thừa, chạy trong CI.
- Định dạng ngày/giờ/số qua `Intl` với locale hiện hành.
- Backend: test khẳng định prompt `generate` (và `rewrite_v1` của T-301) có chỉ thị cùng ngôn ngữ; hàm phát hiện ngôn ngữ đơn giản cho thuộc tính `language` nếu T-212 chưa có.

**Ngoài phạm vi** (để tránh làm thừa)
- File `en.json` hay ngôn ngữ khác, bộ chọn ngôn ngữ (chờ OQ-009).
- Dịch nội dung tài liệu; chọn mô hình embedding đa ngữ (T-208/SP-04).
- Đánh giá chất lượng câu trả lời theo từng ngôn ngữ (CMP-17, T-211/T-310).

## 4. Thiết kế chi tiết

### 4.1 Thư viện và cấu trúc `[Proposed]`

- `i18next` + `react-i18next`; tài nguyên nạp tĩnh (không tải qua mạng), `lng: 'vi'`, `fallbackLng: 'vi'`, `interpolation.escapeValue: false` (React đã thoát ký tự).
- File: `frontend/src/i18n/index.ts` (khởi tạo), `frontend/src/i18n/vi.json`, `frontend/src/i18n/format.ts`.
- `<html lang="vi">` đặt từ ngôn ngữ hiện hành.

```ts
// frontend/src/i18n/format.ts
export const formatTime = (iso: string) => new Intl.DateTimeFormat(i18n.language, { hour: '2-digit', minute: '2-digit' }).format(new Date(iso));
export const formatDayMonth = (iso: string) => new Intl.DateTimeFormat(i18n.language, { day: '2-digit', month: '2-digit' }).format(new Date(iso));
export const formatNumber = (n: number) => new Intl.NumberFormat(i18n.language).format(n);
```

### 4.2 Quy ước khóa

`<màn hoặc vùng>.<thành phần>.<ý nghĩa>`, camelCase, không dùng câu tiếng Việt làm khóa. Tham số bằng `{{tên}}`; số nhiều dùng `_one/_other` của i18next (tiếng Việt chỉ cần `_other`).

```json
{
  "nav": { "library": "Thư viện", "chat": "Hỏi đáp", "history": "Lịch sử", "report": "Báo cáo", "logout": "Đăng xuất", "skip": "Bỏ qua điều hướng" },
  "chat": {
    "newConversation": "Hội thoại mới",
    "composer": { "placeholder": "Đặt câu hỏi về các tài liệu của bạn…", "hint": "Enter để gửi · Shift+Enter xuống dòng", "counter": "{{count}} / 2000", "send": "Gửi", "label": "Câu hỏi của bạn" },
    "disclaimer": "AI có thể sai. Hãy mở trích dẫn để kiểm tra trước khi sử dụng thông tin.",
    "scope": { "buttonAll": "Phạm vi: toàn bộ thư viện ({{count}})", "buttonSome": "Phạm vi: {{count}} tài liệu", "chipAll": "Đang hỏi trên: toàn bộ thư viện ({{count}} tài liệu)", "chipSome": "Đang hỏi trên: {{names}}" },
    "feedback": { "prompt": "Hữu ích?", "helpful": "Hữu ích", "notHelpful": "Không hữu ích" },
    "states": { "progressTitle": "Đang tìm trong tài liệu…", "stepRetrieve": "Tìm đoạn liên quan", "stepGenerate": "Soạn câu trả lời" }
  },
  "errors": {
    "UNAUTHENTICATED": "Phiên đăng nhập đã hết hạn.",
    "FORBIDDEN": "Bạn không có quyền truy cập.",
    "NO_READY_DOCUMENTS": "Chưa có tài liệu nào sẵn sàng để hỏi",
    "UPSTREAM_TIMEOUT": "Dịch vụ AI không phản hồi kịp. Câu hỏi của bạn vẫn được giữ, bạn có thể gửi lại.",
    "UPSTREAM_UNAVAILABLE": "Dịch vụ AI không phản hồi kịp. Câu hỏi của bạn vẫn được giữ, bạn có thể gửi lại.",
    "RATE_LIMITED": "Vui lòng đợi vài giây rồi gửi lại câu hỏi.",
    "unknown": "Đã có lỗi xảy ra. Vui lòng thử lại."
  }
}
```

(Trích đoạn — chữ chính xác lấy nguyên văn từ các file HTML trong `docs/design/html_design/`.)

- **Thông báo lỗi:** FE hiển thị theo `error.code` → `errors.<CODE>`; chỉ dùng `error.message` của server khi không có khóa (fallback). Như vậy chữ giao diện đổi theo ngôn ngữ mà không cần backend.
- Chuỗi trong `aria-label`, `title`, `placeholder`, `alt` cũng phải qua `t()`.
- Nội dung do AI sinh và tên tài liệu **không** qua i18n.

### 4.3 Lint và kiểm khóa

- `eslint-plugin-i18next`, quy tắc `i18next/no-literal-string` mức `error`, `mode: 'jsx-only'`, bỏ qua thuộc tính kỹ thuật (`className`, `data-testid`, `type`, `role`, `href`, `aria-*` có giá trị không phải chữ) `[Proposed]`.
- Script `frontend/scripts/check-i18n.ts` `[Proposed]`: quét `t('...')` trong `src/`, báo lỗi khi khóa thiếu trong `vi.json` hoặc khóa trong `vi.json` không được dùng; chạy trong CI (`npm run i18n:check`).
- Test và file `*.stories.tsx` được miễn quy tắc.

### 4.4 Phía AI (backend)

- Prompt `generate` (T-206) phải có chỉ thị tương đương: "Trả lời bằng đúng ngôn ngữ của câu hỏi gốc của người dùng." Khi có viết lại (T-301), ngôn ngữ xác định theo **câu gốc**, không theo câu đã viết lại.
- Unit test `tests/unit/answering/test_prompt_language.py`: render prompt với câu hỏi tiếng Việt và tiếng Anh, khẳng định chỉ thị có mặt và câu gốc được truyền vào.
- `app/answering/language.py` `[Proposed]` (chỉ khi T-212 chưa điền `language`):

```python
def detect_language(text: str) -> Literal["vi", "en", "other"]:
    """Heuristic: có ký tự đặc trưng tiếng Việt (ă â đ ê ô ơ ư hoặc dấu thanh trên nguyên âm) → 'vi';
    toàn ASCII chữ cái → 'en'; còn lại 'other'. Chỉ dùng cho telemetry, không ảnh hưởng trả lời."""
```

- `question_asked.properties.language` = kết quả trên; không lưu văn bản câu hỏi.

## 5. Các bước thực hiện

1. Cài `i18next`, `react-i18next`, `eslint-plugin-i18next`; tạo `i18n/index.ts`, bọc `App` bằng provider.
2. Kiểm kê chuỗi của mọi trang/component đã có (01, 02, 03, 04, 05, 06, 07, 08, 09) và chuyển sang `vi.json`, chép nguyên văn từ HTML thiết kế.
3. Thay thông báo lỗi bằng ánh xạ `errors.<CODE>`.
4. Thay định dạng ngày/giờ bằng `format.ts`.
5. Bật quy tắc lint mức `error` + script kiểm khóa trong CI; sửa đến khi xanh.
6. Backend: test prompt + (nếu cần) `detect_language` và gắn vào sự kiện `question_asked`.
7. Báo các task FE đang chạy song song trong Sprint 3 (T-302, T-303, T-304, T-307) dùng khóa ngay từ đầu.
